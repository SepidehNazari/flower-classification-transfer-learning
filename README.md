# flower-classification-transfer-learning
Image classification of flowers using transfer learning (InceptionResnet) in TensorFlow/Keras
#🌸 Flower Classification with Transfer Learning

این پروژه با استفاده از **Transfer Learning** و مدل MobileNetV2 تصاویر گل‌ها را طبقه‌بندی می‌کند.  
پروژه در Google Colab توسعه داده شده و شامل مراحل پیش‌پردازش داده، آموزش مدل و ارزیابی عملکرد است.

## 📂 فایل‌ها
- `flower_classification.ipynb` → نوت‌بوک اصلی شامل کد و نتایج
- `requirements.txt` → لیست کتابخانه‌های مورد نیاز (TensorFlow, Keras, NumPy, Matplotlib)
