# 🌸flower-classification-transfer-learning
This project uses **Transfer Learning** with a pre-trained CNN (InceptionResNetV2) to classify flower images.

Files
- `flower_classification.ipynb` → Main Colab notebook
- `requirements.txt` → Dependencies(TensorFlow, Keras, NumPy, Matplotlib)
  
Results
- Accuracy: ~87% on validation set

Technologies
- Python (TensorFlow/Keras)
- Transfer Learning (InceptionResNetV2)
- Google Colab
